{%- comment -%} Buttons linking a research project to its papers. Used in each _research/Project_X.md: {% include project-papers.html %} Papers come from _data/publications.yml: every paper whose "project:" is this file's name (e.g. "Project_5") is listed, grouped by type in the order of the "types:" list. If a type has more than one paper they are numbered, oldest first: Journal Paper 1, 2 ... Each button opens the paper's DOI, or else its "paper" or "manuscript" link. Extra boxes with your own text come from "boxes:" at the top of the project file: boxes: - text: "Industry Data Science Internship Project" link: "" # optional: the box opens this link color: gray # teal, purple, amber, green, red, blue or gray Style: _sass/_custom.scss (section 7). {%- endcomment -%} {%- assign pubs = site.data.publications -%} {%- assign this_project = page.relative_path | split: "/" | last | split: "." | first -%} {%- assign related = "" | split: "" -%} {%- for p in pubs.papers reversed -%} {%- assign project_list = p.project | join: "," | split: "," -%} {%- if project_list contains this_project -%}{%- assign related = related | push: p -%}{%- endif -%} {%- endfor -%} {%- assign box_count = page.boxes | size -%} {%- if related.size > 0 or box_count > 0 -%}
